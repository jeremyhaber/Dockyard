# Dockyard

A free, native macOS file-transfer client (SFTP, FTP/FTPS, and cloud storage through rclone), built to replace FileZilla.

- A connection manager that scales to 200+ accounts, with WHM sync and FileZilla import
- A FileZilla-style dual-pane layout with folder tabs, a folder tree and session restore
- An SSH terminal drawer with su/sudo elevation
- Servers side by side, with transfers relayed through the Mac
- Any connection can be mounted as a drive in Finder

Requires macOS 14+. Swift 6, SwiftUI + AppKit.

The full spec is in [docs/HANDOFF.md](docs/HANDOFF.md).
